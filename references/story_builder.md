# Story Builder — 从分析结果到生物学叙事

> 分析跑完了（QC/聚类/注释/DE/通讯/轨迹/空间），但怎么把这些表格和数字变成一个**有逻辑的生物学故事**？本文件是"结果→故事"的转化方法论。
>
> **谁读这个**：分析完成后、开始画图/写论文前。research-planner 设计时预读（知道故事该怎么讲影响实验设计）；figure-production 出图时读（决定每张 panel 论证什么）。

---

## 1. 故事的三个层次

一篇 CNS 单细胞论文的生物学故事有三层，从上到下：

```
Layer 3 (宏观): 疾病/现象的因果假说
  "POP 的纤维化是由成纤维细胞静息态重塑驱动的，而非经典肌成纤维细胞活化"

Layer 2 (中观): 细胞层面的现象 + 分子层面的机制
  "Quiescent_1 亚群向 Quiescent_2/3 转换，CXCL12 上调，招募 M2 巨噬"

Layer 1 (微观): 数据层面的证据
  "Fibro 比例 44%→57% (padj<1e-40); Quiescent_1→2 DE 基因富集 TGFβ 通路;
   CXCL12-CXCR4 通讯 score 在 Fibro-Mac 对中最高"
```

**故事构建 = 从 Layer 1（数据）往 Layer 3（假说）走，每一步都要有证据支撑。**
LLM 最常犯的错误：直接从 Layer 1 跳到 Layer 3（"CXCL12 上调 → CXCL12 驱动疾病"），跳过了 Layer 2 的中间论证。

## 2. 从结果到故事的方法

> **核心原则：让数据决定故事，不要套模板。** 不同数据适合不同叙事结构。先看清数据里有什么，再选最自然的叙事路径。

### Step 1: 清点发现（What did I find?）

> **前置：先读 `references/discovery_miner.md`** —— 它教你从每类分析输出（DE 表/比例表/CCC/轨迹/niche）中扫描候选发现、排优先级、排雷。

把所有分析结果列成"发现清单"，**不加解读，只陈述数据**。每条发现必须有数据出处（图/统计/数字），没有出处的发现是假说不是发现。

### Step 2: 发现之间的联系（How do findings connect?）

不要套固定模板。观察发现清单，问自己：

- 哪些发现之间有**因果方向**？（A 导致 B，不是 A 伴随 B）
- 哪些发现是**同一现象的不同角度**？（如比例变化 + DE + 轨迹都指向同一细胞群）
- 哪些发现是**独立的副线**？（值得讲但不是主线）
- **哪个发现最让你惊讶？** → 惊讶 = 新颖性的信号，优先考虑做主线

联系可以是：
```
因果链（A→B→C）:    最经典，但不是唯一
收敛（A+B→C）:      多条证据指向同一结论（如 DE+CCC+空间都指向 CXCL12）
发散（A→B+C）:      一个上游变化导致多种下游效应
对比（A vs B）:      两种状态/条件的差异驱动故事
发现→命名:           找到一个新模式，给它命名（CRATER niche / MES-Hyp layer）
```

### Step 2b: 逻辑漏洞扫描（每一步都要有证据支撑）

对发现之间的每一个联系，检查：这个跳跃有直接证据吗？还是我在脑补？

如果某一跳缺证据 → **先补分析再继续**，不要带着漏洞往下走（详见 §2b 完整表格）。

### Step 3: 提炼主结论

主结论 = 一句话，**可证伪的论证性陈述**，不是描述。

```
❌ "We characterized cell heterogeneity in X tissue"
✓ "X is driven by Y mechanism, distinct from the previously assumed Z pathway"
```

### Step 4: Figure 映射（数据决定图，不是图决定数据）

每个 Figure 讲因果链中的**一个环节**。哪种图型最适合取决于你的数据形态——参考 `figure_guide.md` §0 速查卡选图，但最终选择取决于数据本身。

**CNS 论文常见的 Figure 组织模式（非强制模板，仅参考）：**

| 模式 | 适用场景 | 典型结构 | 来源 |
|---|---|---|---|
| **机制驱动型** | 有清晰因果链的数据 | Fig1 图谱→Fig2 现象→Fig3 机制→Fig4 空间/验证→Fig5 模型 | 心衰 Nature 2024, GBM Cell 2024 |
| **资源图谱型** | 大规模 atlas（多供体/多组织） | Fig1 设计+全景→Fig2-3 分区深挖→Fig4-5 跨状态比较→Fig6 资源/工具 | 心脏 Nature 2023, 肾 Nature 2023 |
| **临床预测型** | 配对队列（治疗/预后） | Fig1 队列设计→Fig2 基线特征→Fig3 应答 vs 无应答→Fig4 空间预测因子→Fig5 模型 | TNBC Nature 2023 |
| **发育过程型** | 时间序列/发育梯度 | Fig1 全景→Fig2 时序轨迹→Fig3 命运决定→Fig4 信号中心→Fig5 形态建成 | 瓣膜发育 2026 |
| **方法创新型** | 新算法/新平台 | Fig1 方法概览→Fig2 benchmark→Fig3-4 应用案例→Fig5 新发现 | STARS Nat Commun 2026 |

> **选择依据**：看你的最强发现是什么——因果机制 → 机制驱动型；前所未有的图谱 → 资源型；能预测结局 → 临床型；时空动态 → 过程型。**不要硬选不适合的模式**。

### Step 5: 叙事弧（不是固定模板，是自然推进）

故事弧不是"Hook→Atlas→Finding→Mechanism→Spatial→So-what"的固定序列。
故事弧是**因果链的自然展开**——读者跟着逻辑走，每一步回答上一步引出的问题。

常见的推进方式：
```
"谁变了" → "怎么变的" → "为什么变" → "变了之后怎样" → "所以呢"
"发现了新模式" → "模式是什么" → "怎么验证的" → "有什么意义"
"X 和 Y 不同" → "哪里不同" → "为什么不同" → "不同意味着什么"
```

> **纪律**：因果链里每一步都必须有**独立证据**。不能"因为 A → 所以 B"而没有 B 的数据。只有 A 的数据 → "A is associated with B"（关联），不是 "A causes B"（因果）。

#### Step 2b: 逻辑漏洞扫描 + 补缺分析（mandatory gate）

因果链排完后，**逐环检查每一跳的逻辑是否成立**。如果某一跳缺证据，不是跳过——而是**先补分析再继续**。

**逐环漏洞扫描表**（对因果链的每一跳 A→B 问以下问题）：

| 检查 | 如果失败 | 需要补的分析 |
|---|---|---|
| **A→B 有直接数据支撑吗？** | A 和 B 是两个独立发现，没有连接证据 | 跑连接分析：如 A 是 DE、B 是比例变化 → 跑 A 基因在 B 群体的 violin 确认 |
| **A→B 的方向性确定吗？** | 不知道是 A 导致 B 还是 B 导致 A | 跑轨迹/velocity 确定方向；或 GRN 推断上下游 |
| **A→B 有第三变量混杂吗？** | C 可能同时影响 A 和 B | 跑 partial correlation / condition on C 后重新检验 |
| **A→B 的效应量足以解释 B 吗？** | A 的变化幅度很小但 B 变化很大 | 量化 A 对 B 的贡献度（回归/中介分析） |
| **A→B 在所有样本中一致吗？** | 仅在部分样本中成立 | 按 patient/batch 分层看一致性 |
| **A→B 有正交验证吗？** | 仅一种分析支持 | 补第二种方法或平台（scRNA→空转/IF/RNAscope） |

**常见逻辑漏洞模式**（LLM 高发）：

```
漏洞 1: 跳步
  "Fibro 扩增" → "M2 扩增"（跳过了中间的通讯证据）
  补：跑 CellChat 确认 Fibro→Mac 有 L-R 通讯

漏洞 2: 相关当因果
  "CXCL12 高表达" → "CXCL12 驱动纤维化"（只有相关性没有因果证据）
  补：查是否有扰动数据（KO/OE/阻断剂），没有则措辞降级为 "associated with"

漏洞 3: 缺阴性对照
  "Disease 组某通路激活" → 但没看正常组是否也有该通路的基础活性
  补：画 normal vs disease 对比图

漏洞 4: 缺临床关联
  "发现了一个新 niche" → 但没说这个 niche 与预后/分期/疗效有什么关系
  补：如果有临床数据 → 生存分析/关联分析；没有 → 标注为 limitation

漏洞 5: 缺验证层
  全部分析都基于同一数据集 → 没有独立验证
  补：找一个公开数据集验证；或标注为 "single-cohort, needs validation"

漏洞 6: 组成偏差未排除
  "Cluster A 的 DE 基因" → 但 A 在两组的 cell type 组成不同（Simpson's paradox）
  补：在 A 内部按亚型分层重新检验 DE
```

**漏洞→补分析→重检的迭代规则**：
1. 排好因果链 → 逐环扫漏洞
2. 发现漏洞 → 标记"缺什么分析"
3. **先补分析，拿到结果后再继续构建故事**——不是带着漏洞继续
4. 补不了的分析（没有数据/没有平台）→ 标注为 limitation，措辞降级
5. 补完后重新扫一遍——新分析可能引入新漏洞

> **核心原则**：故事不是"有什么结果讲什么"，而是"逻辑链需要什么就补什么分析"。**缺的分析比多的分析更危险**——审稿人看到跳步就质疑整条链。

### Step 3: 提炼主结论（What is the one sentence?）

从因果链中提炼出**一句话主结论**（Layer 3）：

```
❌ 差的主结论（描述性）: "我们发现了 POP 组织的细胞异质性"
✓ 好的主结论（论证性）: "POP 的纤维化由成纤维细胞静息态重塑驱动
   (非肌成纤维细胞活化)，CXCL12-CXCR4 轴连接纤维化-免疫正反馈"
```

**自检**：
- 主结论是**可被证伪的**吗？（"发现异质性"不可证伪；"静息态重塑驱动"可）
- 主结论的**每个关键词都有 panel 支撑**吗？
- 主结论是否**区别于已知**？（如果与已发表结果完全一样，那你的贡献是什么？）

### Step 4: 组织 Figure 叙事（Which panel tells what?）

把因果链映射到 Figure/Panel：

```
Figure 1 (atlas):
  A: UMAP 全景 → "有哪些细胞" (发现 1 的基础)
  B: 比例柱 → "谁变了" (发现 1)
  C: marker dotplot → "身份可信" (支撑)

Figure 2 (机制: 纤维化主线):
  A: Fibro 亚群 UMAP → "内部重塑" (发现 2)
  B: 比例变化 → "定量" (发现 2)
  C: volcano → "分子机制" (发现 3)
  D: trajectory → "方向性" (发现 2 补充)

Figure 3 (机制: 通讯+空间):
  A: CCC heatmap → "谁跟谁说话" (发现 5)
  B: CXCL12-CXCR4 bubble → "具体哪条轴" (发现 5)
  C: 空间 overlay → "物理邻近" (发现 6)
  D: M2 比例 → "免疫后果" (发现 7)
```

**每张 Figure 只讲一个机制**。两个机制塞一张 = 聚焦不够。

### Step 5: 写出叙事弧（What is the story arc?）

论文的叙事弧 = 因果链的时间/逻辑顺序：

```
开头 (背景): 这个组织/疾病的细胞组成是什么？→ Figure 1
发展 (现象): 哪个细胞群发生了变化？变化多大？→ Figure 2A-B
深入 (机制): 变化的分子基础是什么？→ Figure 2C-D
转折 (整合): 这个变化如何影响其他细胞？→ Figure 3A-B
验证 (空间): 这些相互作用在组织里真的发生吗？→ Figure 3C
收束 (结论): 所以这个疾病的驱动机制是什么？→ Figure 3D + 模型图
```

## 3. 单细胞结果的常见误读（LLM 高发）

| 数据结果 | ❌ 误读（过度推断） | ✓ 正确解读 |
|---|---|---|
| Cluster A 的 marker gene X 高表达 | "X 是 A 的标记基因" | X 在 A 中富集（不代表 X 只在 A 表达或 X 定义 A） |
| Condition 组 Cluster A 比例增加 | "Condition 导致 A 扩增" | A 的比例在 Condition 组更高（关联，非因果；可能是采样偏差） |
| Ligand L 在 CellType1 高表达，Receptor R 在 CellType2 高表达 | "L-R 信号介导 1→2 通讯" | L-R 共表达提示潜在通讯（需蛋白/空间/功能验证） |
| Pseudotime: A → B → C | "A 分化为 B 再分化为 C" | 沿 pseudotime 的排序：A→B→C 是计算排序（需实验验证是否为真实分化） |
| SCENIC+ 发现 Regulon R 在 Cluster A 活跃 | "R 驱动 A 的细胞命运" | R 的活性在 A 中富集（关联，非因果；需 KO/OE 验证） |
| DE 分析发现 Pathway P 富集 | "P 通路被激活" | P 的基因集在差异基因中过表达（可能是少数基因驱动） |
| 空间 niche 内 A-B 共定位 | "A-B 互作" | A-B 空间邻近（有机会互作 ≠ 正在互作） |
| deconvolution 说 spot 内有 cell type X | "确认有 X" | 推断性估计（参考集质量决定可靠性） |
| Niche 在 disease 组变大 | "Niche 导致疾病" | Niche 大小与疾病相关（方向性、因果需扰动实验） |

## 3b. 从 CNS 论文提炼的叙事规范（非模板，是经验规律）

> 以下来自 2023-2026 Nature/Cell/Nat Genet 代表性论文的归纳（案例见 §6.5、§7、§8）。
> **它们是经验规律不是规则**——了解它们，但让你的数据说话。

### 3b.1 什么让审稿人觉得"故事好"

| 特征 | 为什么有效 | 顶刊实例 |
|---|---|---|
| 主结论含**机制方向 + 功能后果**（不只是"发现了 X"） | 可证伪 + 有 translational 价值 | 心衰 Nature 2024: "IL-1β drives fibroblast → targetable" |
| 给发现**命名**（CRATER / MES-Hyp / fibrotic front） | 把观察变成可引用的概念 | GBM Cell 2024, CRC Nat Genet 2025 |
| 有**正交验证**（不是一种方法一种结论） | 消除"方法特异性假阳性"质疑 | 心脏 Nature 2023: scRNA+NMF+IF 三角验证 |
| 有**扰动/功能实验**或**临床终点** | 从"关联"升级到"因果"或"实用" | 心衰 Nature 2024: 抗体阻断; TNBC Nature 2023: 疗效预测 |
| 诚实写**limitation** | 因果未证实时如实说 → 可信度↑ | GBM Cell 2024: 类器官实验失败如实报告 |

### 3b.2 什么让审稿人觉得"故事不好"

| 特征 | 为什么致命 | 怎么避免 |
|---|---|---|
| "我们表征了异质性"——**不可证伪** | 无法判断对错 = 没有贡献 | 改为可证伪陈述（"X 由 Y 驱动而非 Z"） |
| 所有发现**同等权重**，没有主线 | 读者不知道该记住什么 | 聚焦 1-2 个最强发现，其余进 supplementary |
| 空间数据当**装饰**用（删掉空间结论不变） | 审稿人立刻发现空间部分是凑的 | 做"删空间测试"（§7.5）：删掉空间坐标结论还成立吗？ |
| 一个 Figure 塞**两个不相关机制** | 聚焦不够 → 每个都讲不透 | 一个 Figure 一个机制 |
| 比例变化没有排除**组成偏差** | Simpson's paradox → 结论可能反转 | 在目标群内分层重新检验 DE |

### 3b.3 Figure 组织的经验规律

- **UMAP 全文只用 1-2 次**（展示结构和亚群细分）；不用 UMAP 做定量论证
- **每张 Figure 4-6 panel**（CNS 惯例）；≤3 太单薄，>7 信息过载
- **Figure 顺序 = 读者认知顺序**（先全局后局部，先现象后机制，先发现后验证）
- **panel A 是"入口"**：读者眼睛先落到 A——A 要最直观、最有冲击力
- **末尾 panel 或 Figure 常是模型图/总结图**：把前面所有证据浓缩成一张概念图
- **空间图必须配定量**（距离曲线/比例对比）——单独的"好看切片图"不构成证据
- **图型多样化**：连续 3+ 张相同图型 = 视觉疲劳（UMAP→UMAP→UMAP = 差）

## 4. 从"一堆结果"到"一个故事"的检查清单

- [ ] **每条发现都有数据出处**（图/统计/数字）
- [ ] **因果链每一步都有独立证据**（不能跳过中间环节）
- [ ] **逐环漏洞扫描已完成**（Step 2b）——每一跳都有直接证据、方向性确定、无混杂
- [ ] **缺失分析已补齐或标注 limitation**——不是带着漏洞进故事
- [ ] **主结论可被证伪**（不是"我们表征了异质性"）
- [ ] **每张 Figure 只讲一个机制**（两个机制 = 两张 Figure）
- [ ] **Panel 顺序 = 阅读顺序**（陌生人按 A→B→C 能跟上）
- [ ] **措辞区分关联与因果**（"associated with" vs "regulates"）
- [ ] **知道自己的局限**：scRNA 只测 mRNA → 蛋白层面需验证；pseudotime 不是时间；CCC 是假设不是机制
- [ ] **故事有"新"的东西**：复现原文 + 新发现 = 有价值的论文；只复现 = 不够

## 6. 空间转录组的叙事构建

> 调研自 2023-2025 Nature/Cell/Nat Genet 代表性空转论文（案例见 6.5）。
> **空转论文的本质**：把"有什么"（图谱）升级成"在哪、和谁、干什么"（组织逻辑）。一张只有细胞类型分布的空转图不构成论文，能支撑论文的是"空间关系 → 生物学机制 → 功能/临床后果"这条链。

### 6.1 空转 Figure 标准叙事弧

#### 四图主线（适用于大多数机制型空转论文）

| Figure | 角色 | 典型内容 | 叙事功能 |
|---|---|---|---|
| **Fig 1** | 舞台与演员 | 研究设计示意图 + 样本队列 + 技术组合（scRNA+Visium/Xenium）+ QC + 细胞类型总览（UMAP+空间映射） | 证明"设计是多模态、互相验证的" |
| **Fig 2** | 空间图谱 | 空间域识别 + 与 H&E 对照 + 细胞类型空间分布定量 | 证明"分子域与解剖结构对齐，但比解剖更细" |
| **Fig 3** | 核心发现 | niche/邻域分析：找到 1-3 个有生物学意义的空间单元 + 组成定量 + 跨组比较 | 论文的"主卖点"——空间信息第一次产出 scRNA 给不了的结论 |

| Panel | 内容 | 作用 |
|---|---|---|
| **A** | 代表性切片 H&E + 空间 domain/细胞类型着色 | 定场：读者看到组织 |
| **B** | niche/domain 定义 + 各 niche 细胞组成堆叠条形图 | 定义"空间单元" |
| **C** | 目标 niche 丰度/大小在疾病 vs 对照的箱线图（n=患者） | 把观察变成统计结论 |
| **D** | niche 内/外差异通路 GSEA 或 signature 评分空间图 | 给 niche 机制身份（缺氧？炎症？ECM 重塑？） |

### 6.2 空间特有的叙事武器

#### 空间域（domain）：从聚类到生物学意义

合格论证链（缺一不可）：
1. **计算定义**：用考虑空间的方法（BANKSY/BayesSpace/NMF-on-abundance）
2. **组织学对齐**：domain 与 H&E 标注定量匹配
3. **分子身份**：domain marker + 通路注释，domain ≠ 单一细胞类型而是多细胞生态位
4. **超出组织学**：指出 domain 捕捉到了组织学看不见的结构

命名规范：用"分子身份+解剖位置"命名（如 MES-Hyp、myocardial-stress niche），禁止 cluster 编号当生物学名词。

#### 微环境（niche）：定义与论证三件套

- **定义可复现**：明确算法（k-NN 邻域聚类 / 距离带）和参数
- **组成可定量**：niche 细胞构成、跨样本出现频率
- **功能可指向**：niche 内通路富集、L-R 活性、与疾病关联

#### 空间约束的细胞通讯：四级论证强度

| 级别 | 方法 | 结论强度 |
|---|---|---|
| L1 | CellChat/NicheNet 在 scRNA 上跑 | 仅假设生成 |
| L2 | 空间过滤：只保留配体-受体细胞在同一 niche 共富集的 L-R | 空间约束的推断 |
| L3 | Xenium/MERFISH/RNAscope 直接显示物理相邻 | 空间实证 |
| L4 | 扰动实验（类器官/共培养/阻断抗体） | 功能验证 |

论文级别至少到 **L3**（正交平台验证）。仅 L1 = 通讯推断不能当机制结论。

#### 空间梯度/极性

以解剖标志为原点做距离-表达/丰度曲线（如血管-缺氧解耦半径 ~160μm）。
梯度故事必须排除"这只是细胞密度梯度"的平凡解释。

#### 疾病的空间结构重塑

叙事公式：**正常空间秩序 → 疾病中哪个 niche 扩增/新生/瓦解 → 驱动者 → 与结局的关系**

### 6.3 单细胞 + 空转联合叙事

#### 分工原则

| 模态 | 角色 | 不可替代的贡献 |
|---|---|---|
| sc/snRNA-seq | 分辨率上限 + 参考字典 | 精细亚型、稀有状态、GRN 深度 |
| 空转 | 位置与关系 | domain/niche、空间互作、组织学对齐 |

分工叙事模板：**"scRNA 告诉我们有哪些细胞状态；空转告诉我们这些状态住在哪、邻居是谁；两者交叉处才产生机制假设。"**

#### 交叉验证标准动作（七步论证链）

1. scRNA 定义细胞状态 S（marker + 通路）
2. cell2location/RCTD 将 S 映射到空间，发现 S 富集于结构 X
3. H&E/IF 确认结构 X 的组织学身份
4. S 在 X 内与细胞 T 共定位（邻域富集检验，置换检验 p 值）
5. S↔T 存在空间过滤后仍显著的 L-R 轴
6. 正交平台（Xenium/RNAscope/IMC）证实 S-T 相邻
7. 该互作与疾病进展或疗效相关

#### deconvolution 角色定位

它是**假设生成器**和**丰度估计器**，不是细胞身份终审。
写作规范：deconvolution 结论必须配 (a) 参考集可靠性说明 (b) marker 空间共表达佐证 (c) 至少一处正交验证。

### 6.4 空转叙事失败模式

| 症状 | 问题 | 修法 |
|---|---|---|
| "A 和 B 共定位 → A 调控 B" | 共定位只支持"有机会互作"，不支持因果 | 降到"关联"措辞，补 L3/L4 证据，加负面对照 |
| deconvolution 当 ground truth | cell2location 丰度当精确计数 | 双保险：marker 空间共表达 + 一独立平台验证 |
| "Cluster 5 是炎症区" | 单 marker 定名、未与组织学对齐、未证可复现 | 命名 = 分子程序 + 解剖位置；跨样本频率 >20% |
| n=3 切片做患者级结论 | 空间切片数 ≠ 生物学重复数 | 统计用患者；发现去大队列验证 |
| 空间信息可有可无 | 删掉空间坐标结论依然成立 | 空间部分是装饰——要么删要么深化 |

## 7. 叙事构建的实战教训（从真实迭代中提炼）

> 以下教训来自一次瓣膜发育 snRNA+空转 PPT 的完整叙事迭代——从"诚实退守资源型"到"空间预编程"到最终"三层分子架构"的三轮主线重构。

### 7.1 不要直接从数据跳到"退守资源型"

**错误路径**：分析跑完 → 发现信号不够强 → 直接定位"资源型图谱" → 空间部分沦为装饰。

**正确路径**：分析跑完 → 读 discovery_miner §1（发现信号矩阵）扫描所有候选 → 读 §2（评分卡）打分 → 读 §3（排雷）排除伪发现 → **然后**决定故事级别（L1 机制/L2 资源/L3 方法学）。

> **真实案例**：最初把"空间-时间解耦"方向跳过了 discovery_miner 直接构建——后来决策门证伪（成分校正后晚期 marker 6/8 翻号）。如果先跑评分卡的排雷清单，会提前发现 VIC_purity 与 VIC_abundance r=0.936 的共线性问题。

### 7.2 决策门（生死门）是主线故事的必经步骤

任何基于空间梯度的 claim，在进入 PPT 前**必须**过决策门：

| 梯度类型 | 决策门 | 通过标准 | 证伪后果 |
|---|---|---|---|
| VIC 丰度梯度 | 回归 ECM 占比+VIC 纯度+文库大小 | housekeeping 归零 + 目标基因保留 | 信号是成分伪影 |
| core/ring ECM 区划 | 回归 EC/SMC 丰度 | 区划方向不变 + padj<0.05 | 区划是细胞组成驱动 |
| 通路富集空间梯度 | 置换检验 + 成分残差 | 57/198 翻号率 <30% | 原始方向不可信 |

> **教训**：不做决策门直接写 PPT = 在沙子上盖楼。每条基于空间的 claim 都需要自己的决策门。

### 7.3 "so what" 测试——每个发现必须回答

```
发现：弹性基因 ring > core（三时点一致）
so what？→ 瓣膜层状结构在组织学分层前已作为分子空间程序存在
发现：VCAN→CD44 方向翻转（VIC 发送→接收）
so what？→ VIC 在发育中从建造者转为维护者（信号角色转换）
```

**失败的 so what**：
- "VIC 有 7 个亚群" → so what？（亚群本身不是发现，亚群的**空间分工**才是）
- "housekeeping 校正后归零" → so what？（方法学发现不是生物学发现，放方法学页不放主图）

### 7.4 文献新颖性判断的纪律

在构建主线前，**必须**核实关键 claim 的文献地位：
- 用 WebSearch 查关键基因/通路在目标组织的文献（不只靠教科书知识）
- 如果 claim 是"首次发现 X" → 必须有 PubMed 零命中证据
- **真实案例**：FACIT IX (COL9A1/9A3) 被当作 novelty 卖点——后来发现 Clift 2021 Sci Rep 已在人主动脉瓣报告，novelty 不成立

### 7.5 空间转录组的"装饰检测"

**核心检验**：删掉空间坐标，结论是否依然成立？
- 如果成立 → 空间部分是装饰（§6.4 失败模式第 5 条）→ 要么深化要么删掉
- 如果不成立 → 空间做了 scRNA 给不了的工作 → 保留

**真实案例**：
- "VIC 在 niche 定位" → 删掉空间也成立（scRNA 定义了 VIC）→ 装饰 ❌
- "弹性 ring>core 三时点" → 删掉空间不成立（scRNA 不知道空间位置）→ 真发现 ✓
- "467 SVG 形态建成密码" → 删掉空间不成立 → 真发现 ✓

### 7.6 亚群数量：少即是多

VIC 1,155 cells 分 7 群 → 每群 58-274（不稳定，小群可能是噪声）。
合并为 4 群（增殖/ECM/信号/晚期）→ 每群 58-647，生物学意义更清晰。

**规则**：n<2000 cells 的亚群聚类，目标 3-5 群（不是越多越好）。用 marker 生物学相似性合并小群，不要硬凑。

## 9. 探索性思维——从数据中"发现意外"

> 前面的方法论都是**验证驱动**（有假设 → 检验 → 结论）。
> 但 CNS 最高影响力的发现往往是**探索驱动**（没预料到 → 注意到 → 追下去）。
> 这一节教 LLM 怎么"主动发现意外"，而不是只做假设检验的流水线。

### 9.1 怎么注意到"意外"

分析跑完后，不要立刻开始写故事。先**漫途回顾结果**，寻找以下信号：

| 信号 | 含义 | 怎么追 |
|---|---|---|
| 某个 cluster 的 marker 你**认不出来** | 可能是新细胞状态/新亚型 | 查文献：这个基因组合有没有被报道过？没有 → 新发现 |
| 某个细胞群出现在**不该出现的地方** | 可能是迁移/异位/疾病特异 | 空间验证 + 轨迹追溯来源 |
| 两个预期不相关的细胞**高度共变** | 可能有意外的互作/共同调控 | 跑 CCC + GRN + 空间共定位 |
| 某通路在你**没预期的细胞类型**里富集 | 可能是功能重分配/细胞可塑性 | 查该通路在该细胞类型的已知功能 |
| pseudotime 方向**与发育直觉相反** | 可能是疾病状态逆转/去分化 | 用 velocity 独立验证方向 |
| 删掉某个分析步骤后结论**完全改变** | 该步骤是关键脆弱点——要么是核心机制要么是 artifact | 深查这个步骤的假设和稳健性 |
| 某基因在**所有细胞类型中都变化** | 可能是技术因素（batch/detection） | 这是 **red flag**，不是发现——排除技术原因 |
| 不同聚类分辨率给出**完全不同的故事** | 聚类不稳定 | 用多种分辨率 + scSHC 稳定性检验 |

### 9.2 "意外值"评分

不是所有意外都值得追。对每个意外信号打分：

```
高意外值 = 生物学上可解释 + 多个分析交叉支持 + 排除了技术因素
低意外值 = 可能是技术 artifact / 只有一种分析支持 / 没有合理的生物学解释
```

**追高意外值的，放过低意外值的。** 一个真正的意外发现（如 Greenwald 发现 GBM 的缺氧邻接层）比 10 个预期中的确认更有价值。

### 9.3 从"意外信号"到"故事"的转化

发现意外后，叙事策略与常规不同：

```
常规叙事: "我们假设 X，发现 X 成立" → 逻辑清晰但新颖性有限
意外叙事: "我们没有预期到 Y，但 Y 反复出现在多个分析中，
          我们追踪它的来源，发现 Y 揭示了 Z" → 新颖性极高
```

**意外叙事的 figure 结构通常不同**：
- 开头不是"背景+假设"，而是"我们从数据中注意到的模式"
- 中间是"我们怎么排除其他解释 + 怎么确认它是真的"
- 结尾是"这个意外发现意味着什么"

### 9.4 避免"假意外"

| "意外" | 实际是 | 排除方法 |
|---|---|---|
| 新 cluster 只在疾病组出现 | 双联体/低质量细胞/batch | 检查 QC/doublet/batch distribution |
| 基因全局上调 | 检测率差异/批次效应 | 标准化后重检；看 housekeeping 基因 |
| 两个细胞群"共变" | 源于同一 progenitor 的组成连锁 | 分层后重检独立性 |
| niche 只在 1-2 个样本出现 | 个体差异/artifact | 增加样本量；标注为"初步观察" |

> **纪律**：意外发现必须比常规发现**经受更严格的排雷**（discovery_miner §3），因为"意外" = "与预期不符" = "更可能是 artifact"。排除 artifact 后仍然成立的意外 = 真发现。

## 10. 故事的完整性自检（最终交付前）

在交付故事/figure/PPT 之前，回答以下问题。任何回答"不确定"的 → 补分析或标注 limitation。

### 10.1 逻辑完整性

- [ ] 每个结论都有**直接证据**（不是"因为 A 所以 B"但没 B 的数据）
- [ ] 因果链里**没有跳步**（Step 2b 扫过）
- [ ] 有**阴性对照**（正常组/对照组的基线是什么？）
- [ ] 排除了**最 boring 的解释**（"这只是细胞密度差异"/"这只是批次效应"）

### 10.2 证据完整性

- [ ] 每个关键发现**≥2 种独立分析**支持
- [ ] 空间结论有**定量验证**（不只是"看起来共定位"）
- [ ] 如果只有单一数据集 → 明确标注 "needs validation"
- [ ] 比例变化排除了**组成偏差**（分层重检）

### 10.3 新颖性

- [ ] 知道**已有文献做了什么**（WebSearch 验证）
- [ ] 明确**你的贡献是什么**（复现/延伸/全新？）
- [ ] 如果全是复现 → 补充新角度（新组织/新时间点/新方法/新组合）

### 10.4 诚实度

- [ ] 所有"因果"措辞都有**实验证据**（没有 → 降级为"associated with"）
- [ ] limitation **主动列出**（不等审稿人发现）
- [ ] 没有**选择性报告**（跑了 5 种方法只展示效果最好的那种）

### 10.5 读者视角

- [ ] 一个**不熟悉你项目**的人能理解主结论吗？
- [ ] 删掉任何一张图/一段话，**故事链会断吗**？（不断 → 它是冗余）
- [ ] 3 秒扫一眼 figure，能抓到**take-home** 吗？
