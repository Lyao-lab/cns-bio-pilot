# 高分文章分析范式（Paper Paradigms）

> 提炼自 13 篇 IF>15 空转/单细胞文章（Nature/Cell/Cancer Cell/Nat Med/Nat Cardiovasc Res 2023-2026）。
> 本文件不是教你怎么调 API——是教你**像高分文章作者一样思考分析路径**。
> 与 analysis_flow.md 配合：flow 解决"每步做什么"，本文件解决"整体走哪条路线"。

## 三种分析主干（选路线前先判断自己走哪条）

### 链 A：scRNA 主导 → 空间验证

```
scRNA 聚类/轨迹 → 发现候选细胞/通路 → 空间去卷积/映射确认位置
→ LR 空间共定位验证 CCC → 功能验证（敲除/阻断/临床关联）
```

**适用场景**：有 scRNA + 空转数据，scRNA 先发现了有趣信号（疾病特异亚群/轨迹分叉/DE）

**代表文章**：
- **Amrute Nature 2024**（心衰 CCC，最完整范式）：
  多组学 scRNA → 发现 FAP+/POSTN+ 成纤维细胞轨迹分叉 → 空间确认 niche 定位 → LR 预测 IL-1β/CCR2 通讯 → 空间共定位 → 三重功能验证（敲 IL-1R / 敲 IL-1β / 单抗阻断）
- **Chen Cancer Cell 2025**（PDAC 神经侵袭）：
  scRNA + ST 按 NI 状态分层 → 组成/谱系动态映射 → 低 NI = TLS 共定位；高 NI = NLRP3+ 巨噬 + myCAF 包绕神经

**关键决策点**：
1. scRNA 里什么信号值得空间验证？（轨迹分叉亚群 / disease-specific DE / CCC 预测）
2. 空间确认的方式？（去卷积确认存在 / 空间共定位确认邻近 / 空间梯度确认梯度）

### 链 B：空间主导 → scRNA 找机制

```
ST 发现独特空间表型/niche → 回 scRNA 找细胞身份与机制
→ 细胞类型特异性功能验证
```

**适用场景**：空转数据里发现了独特的空间结构/集落/domain，需要解释它是什么、怎么来的

**代表文章**（心脏方向最多——用户重点关注）：
- **Ninh Nature 2024**（心梗 IFNIC）：
  ST 发现梗死边界区干扰素集落（IFNIC）→ 排除法敲除筛查锁定起始细胞（心肌细胞 Irf3 KO 消除 IFNIC，其他细胞敲除无效）→ 功能：IFN 抑制成纤维保护程序
- **Wünnemann NatCardiovasc Res 2025**（急性心梗）：
  成像转录组发现白细胞经心内膜途径募集（非常规路径）→ 空间蛋白组 DVP 找机制 → vWF 上调 → 功能阻断验证
- **van Olst Nat Med 2025**（AD 免疫治疗）：
  ST 对比发现免疫组特异小胶质状态 → scRNA 深挖转录通路 → 空间异质性本身即发现

**关键决策点**：
1. 空间表型是什么？（异常集落 / 边界区 / 梯度 / 邻接模式）
2. 怎么找到驱动细胞？（排除法敲除 / 去卷积 + DE / 空间蛋白组）

### 链 C：结构归纳（多尺度 → 全局架构）

```
空间多组学 → 局部微环境 → 状态对（pairwise）→ 全局架构
→ 驱动因子归因 + 反例检验
```

**适用场景**：大规模/多平台数据，目标是发现组织级别的组织规律（而非单一细胞类型）

**代表文章**：
- **Greenwald Cell 2024**（GBM 五层架构）：
  三尺度递进：局部微环境 → 状态对邻接 → 全局五层 → 归因缺氧（用 IDH 突变低级别胶质瘤作反例检验）
- **Kanemaru Nature 2023**（人心脏 niche）：
  scRNA + ST 整合 → 双轨注释（知识型 + 无监督）→ niche 框架 → 传导系统新发现 → drug2cell 工具产出
- **Liu Cancer Cell 2025**（跨癌种 CAF）：
  7 平台 × 10 癌种 → 发现-验证-表征三段式 → 4 个保守 CAF 亚型
- **CoVarNet Nature 2025**（跨组织多细胞模块）：
  35 组织 → 多细胞模块（CM）定义 → 癌症 = CM 崩解 + 趋同生态系统 cCM02 涌现

**关键决策点**：
1. 用什么尺度归纳？（局部 niche / 状态对 / 全局架构）
2. 怎么证明不是偶然？（跨平台一致性 / 跨样本保守 / 反例检验）

## 主角细胞选择决策树（从 20+ 类型里怎么选主角）

高分文章的选择逻辑——不是随机选，而是 4 条路径之一：

| 选择路径 | 逻辑 | 代表 |
|---|---|---|
| **轨迹分叉出疾病特异亚群** | 轨迹分析发现某 branch 只在 disease 出现 → 该 branch 就是主角 | Amrute: FAP+/POSTN+ 亚群只在心衰出现 |
| **临床分组下差异富集** | 按 disease vs control 分层后，某类型比例/状态显著变 → 它是主角 | Chen PDAC: NLRP3+ 巨噬在高 NI 富集；van Olst: 免疫组特异小胶质 |
| **空间邻接表型锁定** | 某细胞类型在空间上与关键结构/病理区域特异性邻接 | Ninh: IFNIC 在梗死边界；Farah: community 内特化亚群 |
| **与临床结局关联** | 某亚型丰度与生存/预后显著相关 | Liu CAF: 亚型丰度 × 患者生存 |

> **共性**：候选来自"分组×差异"，锁定靠"空间共定位或功能可验证性"。

## 空间验证的三种模式

| 模式 | 方向 | 适用 | 代表 |
|---|---|---|---|
| **A（scRNA→空间）** | scRNA 发现 → 空间去卷积/映射确认存在 | scRNA 有发现需确认空间位置 | Chen PDAC, Tagore NSCLC |
| **B（空间→scRNA）** | ST 发现空间表型 → scRNA 找机制 | 空间有独特结构需解释 | Ninh IFNIC, Wünnemann AMI, van Olst |
| **C（双向）** | scRNA 和空间互相验证 | 最高配——数据充足时首选 | Amrute, Kanemaru, Farah |

> C 是最高配但不是必须——A 和 B 均可独立发 CNS 文章。数据模态决定你能走哪条。

## CCC 空间验证完整链（Amrute 范式）

高分文章的 CCC 不止跑 LIANA——需要完整证据链：

```
scRNA LR 预测（LIANA/CellPhoneDB）
  ↓ 配体在 sender？受体在 receiver？（方向验证）
空间共定位确认（sender 和 receiver 在空间上邻近？）
  ↓ 空间 CCC（COMMOT/spatial LIANA）独立支持？
功能验证（敲除配体/受体 → 表型变化？）
  ↓
临床关联（该通讯强度与疾病严重度/预后相关？）
```

> 每多走一步，结论强度升一级。只有第一步 = "推断性通讯"；走到第三步 = "空间支持的通讯"；五步全走 = "功能验证的通讯"。

## 收敛点规律（故事什么时候"锁定"）

13 篇文章的收敛点几乎都在**"差异/表型首次空间化呈现"**环节：

| 收敛时刻 | 典型表现 | 代表 |
|---|---|---|
| 轨迹分叉出疾病特异亚群 | pseudotime 图上某 branch 只在 disease 出现 | Amrute |
| 空间集落/表型出现 | 空间着色图上出现独特的聚集/边界模式 | Ninh IFNIC, Wünnemann |
| 分层共定位差异出现 | disease vs control 的空间共定位模式不同 | Chen PDAC |
| 保守亚型跨平台确立 | 新分型在多个平台/癌种中可重复 | Liu CAF |
| 分组特异状态出现 | disease 组特有的细胞状态 | van Olst |

> **实践指导**：分析时注意寻找这些"锁定时刻"——一旦出现，故事方向就定了，后续分析围绕它展开。

## 高分文章的高频分析模式（按频率排序）

| 模式 | 频率（13篇中） | 说明 |
|---|---|---|
| 临床/状态分组先验驱动 | 7/13 | 先按临床分层再找差异——分组变量是研究设计锚点 |
| scRNA 定义类型 + 空间定位 | 9/13 | 几乎标配；差异在方向（谁先谁后） |
| 空间共定位作为核心证据 | 8/13 | niche/neighborhood/共定位 = "空间证据"标准形态 |
| CCC/LR + 空间验证 | 5/13 | CellPhoneDB 系 → 空间共定位 → 功能验证 |
| 功能验证收尾 | 8/13 | 高分文章几乎都有湿实验闭环 |
| 空间表型先行 | 4/13 | 独特空间表型本身即故事起点 |

## 分析创新空间（本批文章罕见→可作差异化）

1. **显式 pseudotime → 空间梯度投射**：13 篇中未见——轨迹分析和空间分析是分开做的。把 pseudotime 投射到空间坐标上做"空间梯度"是创新方向。替代方案是"空间伪轨迹"（如 TLS 成熟度梯度，Tang Cancer Cell 2025）。
2. **多细胞模块/生态系统层级分析**：超越单细胞类型中心论，找跨细胞的组织规律（CoVarNet 范式）。
3. **反例检验**：用缺乏表型的样本/条件检验驱动因子假说（Greenwald 用 IDH 突变低级别胶质瘤检验缺氧假说——稳健性论证技巧）。

## 第二轮补充：7 个新方向的 4 个新分析模式

> 来源：发育/免疫/图谱/衰老/植物/肠道/肺 16 篇文章（Nature/Cell/Nat Aging/Nat Plants 2024-2026）

### 新分析主干 D：时空联合建模（发育方向标配）

```
多时间点 scRNA + 多阶段空转
→ 最优传输（moscot）对齐时空坐标
→ 连续时空轨迹（非离散阶段拼接）
→ 信号域/形态发生波的时空动态
```

**与链 A-C 的区别**：链 A-C 是"scRNA 定义 → 空间投射"单向流；时空联合是**时间×空间同时建模**——发育梯度、疾病进展、衰老过程都适用。

**代表**：
- Cell 2024 原肠胚 3D 重建：62 张连续切片 → 3D 时空体积 → 三轴坐标系（AP/ML/DV）约束的轨迹
- moscot（Nature 2025）：最优传输框架，把多时间点 scRNA 与空间数据对齐为连续时空轨迹

**关键决策**：如果数据有多个时间/阶段点 → 考虑时空联合（而非分别分析后拼结论）

### 新分析主干 E：连续组织轴建模（atlas 方向新趋势）

```
空间图谱 → spot 投射到连续组织轴（非离散分区）
→ 沿轴量化微环境梯度
→ 轴上的细胞状态/组成连续变化
```

**与离散 domain 的区别**：之前是"spot → 分到 domain A/B/C"；连续轴是"spot → 轴上的连续位置（如 crypt-villus 位置 0-1）"

**代表**：
- Nature 2024 胸腺图谱：连续组织轴映射取代离散分区
- Cell 2024 衰老 ST 全景：沿衰老梯度的连续变化
- 肠道文章天然有 crypt-villus 轴 / 肠-肛门轴作为先验坐标

### 空间验证模式 D：空间原位扰动（因果级验证）

| 模式 | 方向 | 证据强度 | 代表 |
|---|---|---|---|
| A | scRNA → 空间确认 | 关联 | Chen PDAC |
| B | 空间 → scRNA 机制 | 关联 | Ninh IFNIC |
| C | 双向互验证 | 强关联 | Amrute |
| **D** | **空间原位扰动** | **因果** | **Nature 2025 TRM** |

Nature 2025 TRM 文章做了**空间原位 CRISCR 筛选**（pooled optically encoded perturbation）——在空间上扰动 TGFβ/CXCL9-CXCL10 感知，直接验证 niche 信号决定 TRM 命运。这是从"关联"升级到"因果"的空间验证。

> **实践指导**：如果条件允许（有扰动平台），空间原位扰动是 CCC/niche 假说的终极验证。不需要时，模式 A/B/C 仍可发 CNS。

### 新交叉层：遗传风险空间化（Spatial GWAS）

Nature 2025 文章把 GWAS 复杂疾病位点映射到空间具体细胞类型/位置——为图谱增加"功能注释"层。这是 atlas 类文章的新维度。

### 方向专属注意事项

| 方向 | 独有分析要素 | 注意事项 |
|---|---|---|
| **发育** | 时间×空间联合（moscot）；3D 重建+解剖轴 | 连续切片配准是关键；三轴（AP/ML/DV）坐标定义 |
| **免疫/T 细胞** | 耗竭轨迹连续体；组织驻留 vs 循环 | TRM 状态由 niche 空间 imprinting 决定 |
| **图谱/atlas** | 大样本整合；连续组织轴；跨样本保守性 | 连续轴投射取代离散分区是趋势 |
| **衰老** | 衰老标志物空间化（如 Ig-associated senescence）；SASP 空间梯度 | 衰老标志物需空间重定义（传统 marker 可能不够） |
| **植物** | 分生组织区带；宿主-共生菌共转录组 | 细胞壁 → 单核/原生质体策略；无免疫细胞 |
| **肠道** | crypt-villus 轴作为先验坐标；microniche | 上皮-免疫空间互作是核心 |
| **肺** | 上皮可塑性连续体；纤维化轨迹 | 纤维化 = 上皮 EMT + 成纤维激活 + 免疫驱动 |

### 更新后的分析主干路由器（5 种）

| 链 | 适用场景 | 核心流程 |
|---|---|---|
| **A** | scRNA 有发现 → 空间验证 | scRNA 聚类/轨迹 → 去卷积/映射 → CCC → 功能验证 |
| **B** | 空间发现表型 → scRNA 找机制 | ST domain/niche → scRNA 身份 → 功能验证 |
| **C** | 多尺度 → 全局架构 | 局部 → 状态对 → 全局架构 → 归因+反例 |
| **D** ⭐新 | 多时间点/阶段 | 时空联合建模（moscot）→ 连续轨迹 → 时空动态 |
| **E** ⭐新 | atlas/图谱/连续梯度 | 连续组织轴投射 → 梯度量化 → 跨样本保守性 |

### 更新后的创新空间

4. **pseudotime → 空间梯度投射**（第 1 轮已标注罕见）→ 第 2 轮发现 moscot 部分解决了这个问题（最优传输对齐）
5. **连续组织轴**取代离散分区——atlas 文章的新趋势，适合发育/肠道/衰老梯度
6. **空间原位扰动**——从关联到因果的终极验证（需要实验平台支持）
7. **Spatial GWAS**——遗传风险的空间化解读，atlas 文章的新维度
