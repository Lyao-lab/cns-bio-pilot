# Story Builder — 从分析结果到生物学叙事

> 分析跑完了（QC/聚类/注释/DE/通讯/轨迹/空间），但怎么把这些表格和数字变成一个**有逻辑的生物学故事**？本文件是"结果→故事"的转化方法论。
>
> **谁读这个**：分析完成后、开始画图/写论文前。research-planner 设计时预读（知道故事该怎么讲影响实验设计）；figure-production 出图时读（决定每张 panel 论证什么）。

---

## 1. 故事的三个层次

一篇 CNS 单细胞论文的生物学故事有三层，从上到下：

```
Layer 3 (宏观): 疾病/现象的因果假说
  "POP 的纤维化是由成纤维细胞静息态重塑驱动的，而非经典肌成纤维细胞活化"

Layer 2 (中观): 细胞层面的现象 + 分子层面的机制
  "Quiescent_1 亚群向 Quiescent_2/3 转换，CXCL12 上调，招募 M2 巨噬"

Layer 1 (微观): 数据层面的证据
  "Fibro 比例 44%→57% (padj<1e-40); Quiescent_1→2 DE 基因富集 TGFβ 通路;
   CXCL12-CXCR4 通讯 score 在 Fibro-Mac 对中最高"
```

**故事构建 = 从 Layer 1（数据）往 Layer 3（假说）走，每一步都要有证据支撑。**
LLM 最常犯的错误：直接从 Layer 1 跳到 Layer 3（"CXCL12 上调 → CXCL12 驱动疾病"），跳过了 Layer 2 的中间论证。

## 2. 从结果到故事的五步法

### Step 1: 清点发现（What did I find?）

把所有分析结果列成"发现清单"，**不加解读，只陈述数据**：

```
发现 1: Fibroblast 占比 Normal 44% vs POP 57% (+13pp, padj<1e-40)
发现 2: Fibroblast 内部 Quiescent_1 减少, Quiescent_2/3 增加
发现 3: Quiescent_2/3 DE 基因: COL1A1↑, CXCL12↑, PDGFRB↑ (padj<0.001)
发现 4: SMC 出现中间态群体 (表达 ACTA2+MYH11 混合标记)
发现 5: CXCL12-CXCR4 是 Fibro→Mac 通讯最强轴 (score=0.85)
发现 6: 空间上 CXCL12+ Fibro 与 M2 Mac 在纤维化区域共定位
发现 7: M2 巨噬比例 POP +16.7pp (复现原文)
```

> **纪律**：每条发现必须有数据出处（哪张图/哪个统计）。没有出处的发现是假说不是发现。

### Step 2: 找因果链（How do findings connect?）

把发现按因果顺序排列，找出 **"因为 A → 所以 B → 导致 C"** 的链条：

```
链条 1 (纤维化主线):
  发现2 (亚群重塑) → 发现3 (分子变化: CXCL12↑) → 发现5 (通讯: CXCL12→Mac)
  → 发现6 (空间验证: 共定位) → 发现1 (比例变化: Fibro 扩增)

链条 2 (免疫轴):
  发现3 (CXCL12↑) → 发现5 (CXCL12-CXCR4 通讯) → 发现7 (M2 扩增)

链条 3 (SMC 副线):
  发现4 (SMC 中间态) → 独立于主链，可能是次要发现
```

> **纪律**：因果链里每一步都必须有**独立证据**。不能"因为 A → 所以 B"而没有 B 的数据。只有 A 的数据 → "A is associated with B"（关联），不是 "A causes B"（因果）。

### Step 3: 提炼主结论（What is the one sentence?）

从因果链中提炼出**一句话主结论**（Layer 3）：

```
❌ 差的主结论（描述性）: "我们发现了 POP 组织的细胞异质性"
✓ 好的主结论（论证性）: "POP 的纤维化由成纤维细胞静息态重塑驱动
   (非肌成纤维细胞活化)，CXCL12-CXCR4 轴连接纤维化-免疫正反馈"
```

**自检**：
- 主结论是**可被证伪的**吗？（"发现异质性"不可证伪；"静息态重塑驱动"可）
- 主结论的**每个关键词都有 panel 支撑**吗？
- 主结论是否**区别于已知**？（如果与已发表结果完全一样，那你的贡献是什么？）

### Step 4: 组织 Figure 叙事（Which panel tells what?）

把因果链映射到 Figure/Panel：

```
Figure 1 (atlas):
  A: UMAP 全景 → "有哪些细胞" (发现 1 的基础)
  B: 比例柱 → "谁变了" (发现 1)
  C: marker dotplot → "身份可信" (支撑)

Figure 2 (机制: 纤维化主线):
  A: Fibro 亚群 UMAP → "内部重塑" (发现 2)
  B: 比例变化 → "定量" (发现 2)
  C: volcano → "分子机制" (发现 3)
  D: trajectory → "方向性" (发现 2 补充)

Figure 3 (机制: 通讯+空间):
  A: CCC heatmap → "谁跟谁说话" (发现 5)
  B: CXCL12-CXCR4 bubble → "具体哪条轴" (发现 5)
  C: 空间 overlay → "物理邻近" (发现 6)
  D: M2 比例 → "免疫后果" (发现 7)
```

**每张 Figure 只讲一个机制**。两个机制塞一张 = 聚焦不够。

### Step 5: 写出叙事弧（What is the story arc?）

论文的叙事弧 = 因果链的时间/逻辑顺序：

```
开头 (背景): 这个组织/疾病的细胞组成是什么？→ Figure 1
发展 (现象): 哪个细胞群发生了变化？变化多大？→ Figure 2A-B
深入 (机制): 变化的分子基础是什么？→ Figure 2C-D
转折 (整合): 这个变化如何影响其他细胞？→ Figure 3A-B
验证 (空间): 这些相互作用在组织里真的发生吗？→ Figure 3C
收束 (结论): 所以这个疾病的驱动机制是什么？→ Figure 3D + 模型图
```

## 3. 单细胞结果的常见误读（LLM 高发）

| 数据结果 | ❌ 误读（过度推断） | ✓ 正确解读 |
|---|---|---|
| Cluster A 的 marker gene X 高表达 | "X 是 A 的标记基因" | X 在 A 中富集（不代表 X 只在 A 表达或 X 定义 A） |
| Condition 组 Cluster A 比例增加 | "Condition 导致 A 扩增" | A 的比例在 Condition 组更高（关联，非因果；可能是采样偏差） |
| Ligand L 在 CellType1 高表达，Receptor R 在 CellType2 高表达 | "L-R 信号介导 1→2 通讯" | L-R 共表达提示潜在通讯（需蛋白/空间/功能验证） |
| Pseudotime: A → B → C | "A 分化为 B 再分化为 C" | 沿 pseudotime 的排序：A→B→C 是计算排序（需实验验证是否为真实分化） |
| SCENIC+ 发现 Regulon R 在 Cluster A 活跃 | "R 驱动 A 的细胞命运" | R 的活性在 A 中富集（关联，非因果；需 KO/OE 验证） |
| DE 分析发现 Pathway P 富集 | "P 通路被激活" | P 的基因集在差异基因中过表达（可能是少数基因驱动） |

## 4. 从"一堆结果"到"一个故事"的检查清单

- [ ] **每条发现都有数据出处**（图/统计/数字）
- [ ] **因果链每一步都有独立证据**（不能跳过中间环节）
- [ ] **主结论可被证伪**（不是"我们表征了异质性"）
- [ ] **每张 Figure 只讲一个机制**（两个机制 = 两张 Figure）
- [ ] **Panel 顺序 = 阅读顺序**（陌生人按 A→B→C 能跟上）
- [ ] **措辞区分关联与因果**（"associated with" vs "regulates"）
- [ ] **知道自己的局限**：scRNA 只测 mRNA → 蛋白层面需验证；pseudotime 不是时间；CCC 是假设不是机制
- [ ] **故事有"新"的东西**：复现原文 + 新发现 = 有价值的论文；只复现 = 不够

```
## 6. 空间转录组的叙事构建

> 调研自 2023-2025 Nature/Cell/Nat Genet 代表性空转论文（案例见 6.5）。
> **空转论文的本质**：把"有什么"（图谱）升级成"在哪、和谁、干什么"（组织逻辑）。一张只有细胞类型分布的空转图不构成论文，能支撑论文的是"空间关系 → 生物学机制 → 功能/临床后果"这条链。

### 6.1 空转 Figure 标准叙事弧

#### 四图主线（适用于大多数机制型空转论文）

| Figure | 角色 | 典型内容 | 叙事功能 |
|---|---|---|---|
| **Fig 1** | 舞台与演员 | 研究设计示意图 + 样本队列 + 技术组合（scRNA+Visium/Xenium）+ QC + 细胞类型总览（UMAP+空间映射） | 证明"设计是多模态、互相验证的" |
| **Fig 2** | 空间图谱 | 空间域识别 + 与 H&E 对照 + 细胞类型空间分布定量 | 证明"分子域与解剖结构对齐，但比解剖更细" |
| **Fig 3** | 核心发现 | niche/邻域分析：找到 1-3 个有生物学意义的空间单元 + 组成定量 + 跨组比较 | 论文的"主卖点"——空间信息第一次产出 scRNA 给不了的结论 |
| **Fig 4+** | 机制与功能 | 空间约束 L-R 通讯、梯度/轨迹、正交验证（Xenium/RNAscope/IF）、临床关联 | 把共定位升级成"通讯"，把通讯升级成"功能后果" |

#### 标准模板：6-panel 空转主 Figure（A-F）

| Panel | 内容 | 作用 |
|---|---|---|
| **A** | 代表性切片 H&E + 空间 domain/细胞类型着色 | 定场：读者看到组织 |
| **B** | niche/domain 定义 + 各 niche 细胞组成堆叠条形图 | 定义"空间单元" |
| **C** | 目标 niche 丰度/大小在疾病 vs 对照的箱线图（n=患者） | 把观察变成统计结论 |
| **D** | niche 内/外差异通路 GSEA 或 signature 评分空间图 | 给 niche 机制身份（缺氧？炎症？ECM 重塑？） |
| **E** | niche 内富集 L-R 对气泡图 + 代表对空间双标图 | 从"在一起"推进到"在对话" |
| **F** | niche 丰度与预后/疗效关系 + 模型图 | 回答"so what" |

> 审稿人对每一格的问题依次是："在哪→真的更多吗→是什么→和谁说话→重要吗"

### 6.2 空间特有的叙事武器

#### 空间域（domain）：从聚类到生物学意义

合格论证链（缺一不可）：
1. **计算定义**：用考虑空间的方法（BANKSY/BayesSpace/NMF-on-abundance）
2. **组织学对齐**：domain 与 H&E 标注定量匹配
3. **分子身份**：domain marker + 通路注释，domain ≠ 单一细胞类型而是多细胞生态位
4. **超出组织学**：指出 domain 捕捉到了组织学看不见的结构

命名规范：用"分子身份+解剖位置"命名（如 MES-Hyp、myocardial-stress niche），禁止 cluster 编号当生物学名词。

#### 微环境（niche）：定义与论证三件套

- **定义可复现**：明确算法（k-NN 邻域聚类 / 距离带）和参数
- **组成可定量**：niche 细胞构成、跨样本出现频率
- **功能可指向**：niche 内通路富集、L-R 活性、与疾病关联

#### 空间约束的细胞通讯：四级论证强度

| 级别 | 方法 | 结论强度 |
|---|---|---|
| L1 | CellChat/NicheNet 在 scRNA 上跑 | 仅假设生成 |
| L2 | 空间过滤：只保留配体-受体细胞在同一 niche 共富集的 L-R | 空间约束的推断 |
| L3 | Xenium/MERFISH/RNAscope 直接显示物理相邻 | 空间实证 |
| L4 | 扰动实验（类器官/共培养/阻断抗体） | 功能验证 |

论文级别至少到 **L3**（正交平台验证）。仅 L1 = 通讯推断不能当机制结论。

#### 空间梯度/极性

以解剖标志为原点做距离-表达/丰度曲线（如血管-缺氧解耦半径 ~160μm）。
梯度故事必须排除"这只是细胞密度梯度"的平凡解释。

#### 疾病的空间结构重塑

叙事公式：**正常空间秩序 → 疾病中哪个 niche 扩增/新生/瓦解 → 驱动者 → 与结局的关系**

### 6.3 单细胞 + 空转联合叙事

#### 分工原则

| 模态 | 角色 | 不可替代的贡献 |
|---|---|---|
| sc/snRNA-seq | 分辨率上限 + 参考字典 | 精细亚型、稀有状态、GRN 深度 |
| 空转 | 位置与关系 | domain/niche、空间互作、组织学对齐 |

分工叙事模板：**"scRNA 告诉我们有哪些细胞状态；空转告诉我们这些状态住在哪、邻居是谁；两者交叉处才产生机制假设。"**

#### 交叉验证标准动作（七步论证链）

1. scRNA 定义细胞状态 S（marker + 通路）
2. cell2location/RCTD 将 S 映射到空间，发现 S 富集于结构 X
3. H&E/IF 确认结构 X 的组织学身份
4. S 在 X 内与细胞 T 共定位（邻域富集检验，置换检验 p 值）
5. S↔T 存在空间过滤后仍显著的 L-R 轴
6. 正交平台（Xenium/RNAscope/IMC）证实 S-T 相邻
7. 该互作与疾病进展或疗效相关

#### deconvolution 角色定位

它是**假设生成器**和**丰度估计器**，不是细胞身份终审。
写作规范：deconvolution 结论必须配 (a) 参考集可靠性说明 (b) marker 空间共表达佐证 (c) 至少一处正交验证。

### 6.4 空转叙事失败模式

| 症状 | 问题 | 修法 |
|---|---|---|
| "A 和 B 共定位 → A 调控 B" | 共定位只支持"有机会互作"，不支持因果 | 降到"关联"措辞，补 L3/L4 证据，加负面对照 |
| deconvolution 当 ground truth | cell2location 丰度当精确计数 | 双保险：marker 空间共表达 + 一独立平台验证 |
| "Cluster 5 是炎症区" | 单 marker 定名、未与组织学对齐、未证可复现 | 命名 = 分子程序 + 解剖位置；跨样本频率 >20% |
| n=3 切片做患者级结论 | 空间切片数 ≠ 生物学重复数 | 统计用患者；发现去大队列验证 |
| 空间信息可有可无 | 删掉空间坐标结论依然成立 | 空间部分是装饰——要么删要么深化 |

### 6.5 案例分析（5 篇顶刊空转论文）

#### 案例 1：人类心脏空间 niche 图谱（Kanemaru et al., Nature 2023）
- **Main message**：70 万细胞心脏多模态图谱，发现胶质-起搏细胞信号、心外膜免疫防御 niche、心肌应激 niche（疾病中扩增的重构前体）
- **Figure 结构**：Fig1 图谱 → Fig2 niche 定义（cell2location+NMF）→ Fig3 起搏细胞深挖 → Fig4 药物重定位 → Fig5 心外膜免疫
- **空间增强点**：niche 由 NMF factor 定义；L-R 推断限定在 niche 内共富集细胞

#### 案例 2：胶质母细胞瘤五层空间架构（Greenwald et al., Cell 2024）
- **Main message**：GBM 存在缺氧驱动的五层空间架构，L2"缺氧邻接层"是病理不可见的新结构
- **Figure 结构**：Fig1 Visium → Fig2 空间 metaprogram → Fig3 CODEX 验证 → Fig4 空间连贯性分层 → Fig5 状态互作 → Fig6 五层模型
- **空间增强点**：梯度变生物物理量（血管-缺氧 ~160μm 解耦半径）；因果未证实时如实写 limitation

#### 案例 3：TNBC 免疫治疗空间预测因子（Wang et al., Nature 2023）
- **Main message**：基线肿瘤免疫细胞的空间组织（而非单纯丰度）预测免疫治疗应答
- **Figure 结构**：Fig1 试验+IMC → Fig2 基线预测因子 → Fig3 增殖分数预测 → Fig4 治疗动态 → Fig5 应答 → Fig6 多变量模型
- **空间增强点**：空间特征是"预测变量"而非"描述"——每张空间图对应一个结局终点

#### 案例 4：肾脏损伤 niche 图谱（Lake et al., Nature 2023）
- **Main message**：定义"适应性 vs 不良修复"两类空间损伤 niche，后者与纤维化进展关联
- **空间增强点**：同一细胞类型在不同 niche 有不同命运——只有空间数据能讲

#### 案例 5：结直肠癌 Visium HD 空间免疫图谱（Oliveira et al., Nat Genet 2025）
- **Main message**：促瘤（SPP1+巨噬）与抗瘤（趋化因子焦点+克隆扩增 T 细胞）两类空间 niche 的平衡塑造 CRC 进展
- **Figure 结构**：Fig1 多平台设计 → Fig3 deconvolution → Fig4 肿瘤边缘 50μm 带 → Fig5 双巨噬 niche → Fig6 T 细胞重定位 → Fig7 Xenium+TCR 正交验证
- **空间增强点**：正反派 niche 对仗叙事 + 定制探针把 TCR 克隆钉进空间坐标
                    （写作：文字组织）
```
