> 分析跑完了（DE 表 / 比例表 / CellChat 输出 / pseudotime / SCENIC / niche），怎么从中**扫出真正的生物学发现**？
> 本文件是 story_builder.md 的前置——先把候选发现挖出来、排雷、排优先级，再进 story_builder 构建叙事。
>

## 1. 发现信号矩阵（从每类分析输出里扫描候选发现）

> 每种分析输出的"发现信号"长得不一样。以下矩阵教你怎么扫、什么值得追、什么是噪音。

### 比例/组成分析（cell type proportion）

| 信号 | 含义 | 故事潜力 | 跟进动作 |
|---|---|---|---|
| 某细胞群比例 disease vs ctrl 差异 >10pp 且 padj<0.01 | 组成重塑 | ★★★ | 细分该群亚型 + 轨迹分析 |
| 比例变化方向与轨迹推断一致 | 状态转换（不是采样偏差） | ★★★ | velocity 验证方向 |
| 比例变化仅在新 cluster 出现 | 可能是聚类 artifact | ★ | 检查双联体/批次 marker |
| 比例变化跨样本不一致 | 个体异质性（可能是 story 也可能是噪音） | ★★ | 按 patient 分层看 |

### 差异表达（DE / pseudobulk DESeq2）

| 信号 | 含义 | 故事潜力 | 跟进动作 |
|---|---|---|---|
| Top 上调基因集中于某一通路（GSEA/ORA） | 通路激活 | ★★★ | 查通路配体 → CCC 候选 |
| 上调基因中有分泌配体（L-R 数据库匹配） | 通讯故事候选 | ★★★ | 跑 CellChat/LIANA 确认 |
| DE 基因在该群所有细胞都上调 vs 仅少数驱动 | 均匀变化 vs 少数驱动 | ★★ vs ★ | 看 violin 分布形态 |
| 某基因 log2FC 极大但 padj 临界 | 可能是低表达噪声 | ★ | 查 baseMean |
| 疾病组特异性新 marker | 新亚型/新状态 | ★★★ | 亚群细分 + 空间验证 |

### 通路富集（GSEA / ORA / decoupler）

| 信号 | 含义 | 故事潜力 | 跟进动作 |
|---|---|---|---|
| 免疫/炎症/纤维化/EMT 等明确通路富集 | 经典疾病机制 | ★★ | 有已知文献 → 延伸而非全新 |
| 意料之外的通路富集（如代谢/神经/发育） | 新机制线索 | ★★★ | 追：这个通路在这类细胞里做什么 |
| 多个细胞群共享同一通路变化 | 系统性重塑 | ★★★ | 做跨群比较图 |
| 仅 GSEA NES 显著但 leading edge 基因无变化 | 可能是富集假阳性 | ★ | 查 leading edge 基因表达 |

### 细胞通讯（CellChat / LIANA / NicheNet）

| 信号 | 含义 | 故事潜力 | 跟进动作 |
|---|---|---|---|
| 某配体-受体对在疾病组特异性增强 | 通讯轴重塑 | ★★★ | 查配体细胞+受体细胞的空间共定位 |
| 通讯方向反转（disease: A→B 变成 B→A） | 信号重编程 | ★★★ | 追上游调控因子 |
| 多个 L-R 对共享同一配体细胞 | 该细胞是信号枢纽 | ★★★ | 做该细胞的 GRN/SCENIC |
| 仅 CellChat score 高但无空间共定位证据 | 可能是假阳性 | ★ | 需空转或 IF 验证 |

### 轨迹/伪时间（CellRank / Monocle / PAGA）

| 信号 | 含义 | 故事潜力 | 跟进动作 |
|---|---|---|---|
| 伪时间方向与疾病进展一致 | 状态转换是疾病驱动 | ★★★ | velocity 验证 + 扰动实验 |
| 某分支点在疾病组偏向一极 | 命运决定重塑 | ★★★ | 查分支点 transcription factor |
| 轨迹仅在疾病组出现（健康组无） | 疾病特异路径 | ★★★ | 追路径起点和终点 |
| 轨迹方向与 RNA velocity 不一致 | 可能是 pseudotime artifact | ★ | 需独立方向性证据 |

### 空间 niche/domain（BANKSY / BayesSpace / NMF）

| 信号 | 含义 | 故事潜力 | 跟进动作 |
|---|---|---|---|
| 某 niche 在疾病组扩增/新生 | 组织重塑 | ★★★ | 定量 niche 丰度 + 临床关联 |
| 某 niche 内 L-R 活性显著高于其他 | 微环境通讯 | ★★★ | 空间双标图 + IF 验证 |
| niche 跨样本可复现（>20% 样本出现） | 真实结构 | ★★★ | 命名 + 定义 marker |
| niche 仅在 1-2 个样本出现 | 可能是 artifact | ★ | 增加样本量验证 |
| 疾病-正常的空间结构差异可量化 | 组织级重塑 | ★★★ | 做距离曲线/组成对比 |

## 2. 发现优先级评分卡

对每条候选发现打分（1-3），总分 ≥10 进入因果链构建，<8 进附录。

| 维度 | 1 分 | 2 分 | 3 分 |
|---|---|---|---|
| **效应量** | 比例 <5pp / log2FC <0.5 | 5-10pp / 0.5-1 | >10pp / >1 |
| **统计显著性** | padj 0.01-0.05 | padj 0.001-0.01 | padj <0.001 |
| **可验证性** | 仅一种分析支持 | 两种分析交叉支持 | 三+种/正交平台支持 |
| **新颖性** | 与已发表完全相同 | 延伸已知（新角度/新组织） | 全新发现（新结构/新轴/新概念） |
| **疾病/临床相关性** | 无直接关联 | 机制上可关联 | 有临床数据可挂钩 |

> **取舍规则**：如果两条候选因果链竞争主线，选**可验证性**更高的那条（能在现有数据+1-2 个实验内升到更高证据级）。最美但不验证的假说 < 朴素但可验证的发现。

## 3. 伪发现排雷清单

每个"发现"进因果链前，过一遍以下检查：

| 检查项 | 如果失败 | 处理 |
|---|---|---|
| **比例变化**：检查 disease/ctrl 组的 sample 数是否均衡？batch 是否混杂？ | 不均衡/batch 混杂 → 可能是采样偏差 | 按 batch 分层看；跑 batch_correction 后重新检验 |
| **新 cluster**：检查该 cluster 的 doublet score / QC metric / batch 分布 | doublet 高/QC 差/单 batch → 可能是 artifact | 过滤后重新聚类 |
| **DE 基因**：检查是否由 <5% 的细胞驱动 | 少数驱动 → DE 信号不代表群级变化 | 看 violin 分布；考虑排除 outlier 细胞 |
| **通路富集**：检查 leading edge 基因是否独立变化 | 全靠 1-2 个基因 → 富集可能是假阳性 | 逐基因验证 |
| **通讯轴**：检查是否仅基于一种方法（CellChat only） | 单方法 → 可能是方法特异性假阳性 | 跑 LIANA consensus 多方法对比 |
| **轨迹**：检查是否有独立方向性证据（velocity / 实验数据） | 无 → pseudotime 可能是 artifact | 需 velocity 或 clone tracing 验证 |
| **空间 niche**：检查跨样本出现频率 | <20% 样本 → 可能是个体特异而非通用结构 | 增加样本或标注为"初步发现" |

## 4. 负结果与降级路径

分析做完没有强信号？这是最常见的真实场景。不要硬编故事——降级：

| 级别 | 条件 | 故事类型 | main message 模板 | so-what 着陆 |
|---|---|---|---|---|
| **L1 机制故事** | 有 1-2 个候选信号（但证据不够强） | 探索性机制假说 | "X 可能通过 Y 机制参与 Z，需进一步验证" | 假说生成（后续实验方向） |
| **L2 图谱/资源故事** | 数据量大/覆盖全/技术新 | 资源型论文 | "首个 X 组织的单细胞+空转图谱，定义了 Y 个细胞状态和 Z 个空间 niche" | 数据资源（供社区使用） |
| **L3 方法学故事** | 分析流程有创新 | 方法学论文 | "我们开发了 X 流程，在 Y 数据上优于现有方法" | 工具/流程（GitHub + 文档） |

> **规则**：L1 的措辞必须保守（"suggest"/"may"/"候选"），不能用"prove"/"demonstrate"。审稿人能区分"有数据的假说"和"过度解读的噪音"。
